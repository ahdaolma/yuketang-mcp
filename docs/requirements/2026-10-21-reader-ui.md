# 用户确认的阅读与界面要求

记录日期：2026-10-21。以后续用户明确修订为准。

1. 删除顶部重复的“课程”“笔记”页面大标题，底部导航文字保留；**上课卡片保留**，不要再把标题与卡片混为一谈。
2. 没有本次实际启动上课模式时不得显示上课圆球，旧课堂和恢复记录只提供继续入口。本次正在上课的圆球仍支持短按暂停/继续、拖动，长按无动作；离开 App 的系统悬浮窗继续跟课。
3. **系统状态栏继续隐藏，保留应用额外显示的时间。** 压缩刘海安全留白，时间与刘海占位合成一层，避免顶部重复留空；不要压缩到极限，保留安全间距和展开标题空间。
4. 笔记顶部横向工具条移除，阅读工具一直由悬浮按钮进入；展开后工具**纵向排列**。
5. 阅读菜单定位稳定，限高、可滚动、分组，关闭入口固定；不得出现贴顶部贯穿全屏的细长弹出列表。
6. 连续滚动模式必须一直向下看完所有页，无需再点下一段。
7. 点击翻页模式必须只靠点正文右侧看完全部内容、点左侧返回；**不得新增底部上一页/下一页条**。一页超过一屏时先翻页内剩余屏，再进入下一原页。横滑使用同样按屏推进逻辑，不得跳过文字或图片。
8. **2026-10-22 用户修订，覆盖原先与时间同行的要求：** 摄像头会遮住中央标题，因此连续滚动的吸顶标题改到时间行下面，适当加高笔记顶部区域。时间和页码仍在上层，标题独占下层宽幅区域，固定预留高度以免显隐推动正文。原始标题滚出后，吸顶标题从下缘缓慢向上露出并淡入，消失反向向下。吸顶标题单行，超长省略；正文原始标题保持完整。翻页模式不显示这种吸顶标题。
9. 笔记独立字号可调整、实时预览并持久化；不要连带改变按钮、菜单字号。
10. 笔记内查找需要命中词高亮、当前位置/总数、上一处/下一处，并定位到具体文字；只跳到分段开头不算满足。
11. 原有目录跳转、阅读位置记忆、图片原页/批注、个人标记与备注、笔记草稿继续保留。
12. 不在本地构建、测试、启动模拟器或运行 ADB。源码可在本地编辑；构建及实际操作回归使用 GitHub Actions，下载云端 APK、报告和截图再核验。
13. **页码固定在右上角，与时间同行**，不能放底部或额外建顶栏，滚动实时更新；按原页计数，长页内按屏推进不能虚增原页数。
14. 笔记阅读底部只留收纳工具的悬浮按钮；不留页码、翻页条或导航栏。返回列表、设置等操作通过纵向收纳工具提供。
15. **所有展开列表都要统一限高**，不只是某一个笔记菜单；包括操作、目录、查找结果、模型、课程/课堂、资料、分类、标签与复习、备注、历史与回收站等。过多内容内部滚动，横屏和大字号也要能使用，面板关闭入口固定可见。
16. 展开列表使用现代、宽幅圆角面板，操作行分组、留白和选中状态清晰；不再使用窄长旧式锚点下拉框。
17. 修复回归问题后交付正式 1.0，发布前检查云端全量结果、截图、固定签名和覆盖安装；不得把旧版结果当成新版验证。
18. 设置增加“关于雨课伴学”，集中显示本项目 GitHub 地址、项目声明和实际安装版本号；项目地址可点击打开。
19. 交互不触发手机实际震动；按钮、开关、笔记长按、选词和课堂悬浮球保留视觉与功能反馈，关闭应用的触感反馈请求。
