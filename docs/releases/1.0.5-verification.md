# 雨课伴学 1.0.5 验证记录

版本1.0.5，构建号28。最终云端验收完成，公开发布结果在完成上传与公开下载校验后补记。

## 本次修复

| 用户报告/回归发现 | 处理及影响检查 |
| --- | --- |
| 点击翻页也被滑动触发 | 横滑所有权仅在横向模式建立；点按超过系统触摸阈值后永久取消本次候选，拖回原点也不翻页。保留原生选字、链接、备注与图片手势归属。 |
| 横向浏览还能上下滚动 | 两种翻页模式关闭直接纵向触摸滚动，保留原ScrollState程序定位。长原页继续先逐屏读完再跨页；查找、目录与恢复不另造分页逻辑。连续模式维持自然上下滚动。 |
| 两侧不参与横翻动画 | 纸面及两份动画快照覆盖整个可用阅读宽度；20dp侧边距、最大840dp正文在快照内部保留，不拉伸文字。时间/页码与底部收纳工具固定。 |
| 装饰留白多制造一次翻屏 | 内部底部8dp装饰从有效正文高度中排除，仍检查真正的末行/原图和工具遮挡。非整数密度按两侧分别取整的物理像素计算native正文宽度。 |
| 连续阅读恢复时布局重入 | Scaffold测量子组合时启动的恢复命令会立即scrollToItem并同步重测列表。保留命令立即取得取消所有权，在连续模式首次定位前跨过一个帧边界，退出当前测量调用栈；不吞异常、不加固定毫秒等待、不改变横向翻页响应。 |

## 根因、方案与新增风险

保留原生TextView、统一可取消命令和现有仿真/覆盖动画。将整幅纸面内的正文限宽，优于拉伸原窄幅快照或删除正文留白；保留最多当前/目标两个视口快照及原有内存不足时的原生目标定位。关闭触摸滚动仍保留程序ScrollState行为，依据[Compose Scroll.kt](https://android.googlesource.com/platform/frameworks/support/+/79353bfe455684ea90e2973087df508359dcecb3/compose/foundation/foundation/src/commonMain/kotlin/androidx/compose/foundation/Scroll.kt)。

完整失败堆栈中的scrollToItem→forceRemeasure与[LazyListState官方源码](https://android.googlesource.com/platform/frameworks/support/+/dd97834aa54671ee1f56d65fa46668b4ffeb57e8/compose/foundation/foundation/src/commonMain/kotlin/androidx/compose/foundation/lazy/LazyListState.kt)一致。仅跳过首页0定位不能保护其他恢复位置；整体改用requestScrollToItem会改变后续就绪、测量与锚点语义，因此只在连续preparePage的首次即时滚动前使用可取消帧边界。新增真实StudyApp预打开保存位置、六轮宽度/字号变化及关闭重进，检查目标正文行实际可见；搜索、模式切换、课堂追加、长页和连续小幅回退一起回归。

首个API26平板夹具误用模拟器不支持的2560px强制宽度，日志确认真实上限2160px。测试使用支持的2160x1600，保留真实可用宽度大于880dp、native正文840dp上限及精确像素宽度、整幅纸面边界断言；API35仍使用2560x1600。旧UiAutomation在改尺寸后可能返回null，API26前置图改取实际纸面captureToImage；中间帧必须超过50个采样纸面像素变化后保存同一张已检查位图。没有修改应用窗口策略。

每项修订检查取消/状态、手势归属、窗口/字号、性能/内存及旧数据：横翻没有逐指针重排或重新解析Markdown，连续定位仅新增帧边界，过期命令仍由原代次和取消机制阻止回写。
