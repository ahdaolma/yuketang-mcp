## 本批范围

- 修复普通提问、课件/笔记讲解、整理结果及历史默认会话名称；保留自定义名称和每个会话的草稿。
- 明确课程/课堂/课件/页面层级及逐级返回；整份已开放课件默认选择，不静默截断 50 页，逐页保存可中止；自定义范围仍明确保留跨度限制及就地错误提示。
- 对话可检索实际已保存笔记，返回按 ID 绑定的原笔记卡片，编辑后下一次请求带入最新正文、标记/备注和版本变化摘要。未保存草稿、回收站和未实际提供的图片不冒充已读；长文节选明确标注。
- 对话原文保存不调用 AI；AI 整理与原文保存分开，成功结果返回真实笔记卡片。从卡片打开后可直接返回原对话。

- 阅读操作合并到一个有固定关闭的面板，查找/编辑/备注直达；移动笔记时可原地创建目标笔记本/章节；常用模型选择不要求展开连接凭据，离开后不再由旧请求弹窗。
- 课程页保留唯一常驻上课卡片，笔记列表和课程头部重复入口收拢，主动打开的统一管理保留完整控制。

## 收尾审计阻断项

- 网络停止：将协程取消绑定到单次 HTTP 调用并覆盖响应体读取；关闭浏览资料仅取消该浏览任务，不取消课堂/预览或已完成导入。新增延迟请求、操作解锁及互不干扰的设备测试，待云端执行。
- AI 晚到响应：JSON 与 SSE 发出文字前共同检查取消状态；取消与文字回调串行，避免停止后的旧回答污染下一次回答。新增 Chat Completions / Responses 延迟 JSON 的实际请求回归。
- 查看课堂笔记：按课堂 noteId 打开，保留其他笔记未保存修改的保护，不再仅切换到笔记标签。
- 图片批注：打开状态随 Activity 恢复，未保存笔画和撤销历史留在内存编辑会话；只有明确保存才写入原批注。
- 模型草稿：名称、地址、密钥、模型和输入方式留在 ViewModel 内存，跨标签与 Activity 重建保留；明确保存/取消后清理，密钥不写入 SavedState。
- 以上修复及新云端回归未验收前保持不发布。

取消保证限定于普通 Rain 请求、模型目录和 AI 响应读取。过期 ChatGPT 授权的轮换及加密落盘仍保留不可中断事务，避免丢失轮换后的凭据；不将合成 API Key 测试冒充真实套餐授权刷新验证。
