## 收尾审计修复及回归

- 网络停止：将协程取消绑定到单次 HTTP 调用并覆盖响应体读取；关闭浏览资料仅取消该浏览任务，不取消课堂/预览或已完成导入。延迟请求、操作解锁及取消隔离设备测试已通过。
- AI 晚到响应：JSON 与 SSE 发出文字前共同检查取消状态；取消与文字回调串行，避免停止后的旧回答污染下一次回答。新增 Chat Completions / Responses 延迟 JSON 的实际请求回归。
- 查看课堂笔记：按课堂 noteId 打开，保留其他笔记未保存修改的保护，不再仅切换到笔记标签。
- 图片批注：打开状态随 Activity 恢复，未保存笔画和撤销历史留在内存编辑会话；只有明确保存才写入原批注。
- 模型草稿：名称、地址、密钥、模型和输入方式留在 ViewModel 内存，跨标签与 Activity 重建保留；明确保存/取消后清理，密钥不写入 SavedState。
- 全局提示条按实际可见高度让开操作区域，避免与键盘重复占位；提示关闭后恢复内容空间。实际触摸保存、状态和落盘断言，以及课程/阅读操作可达性均通过。
- 上述审计项对应的取消、晚到 JSON、课堂目标笔记、模型与图片 Activity 重建、提示条覆盖等用例均在最终 117 项中通过；早期失败记录保留，未作为最终成功依据。

取消保证限定于普通 Rain 请求、模型目录和 AI 响应读取。过期 ChatGPT 授权的轮换及加密落盘仍保留不可中断事务，避免丢失轮换后的凭据；不将合成 API Key 测试冒充真实套餐授权刷新验证。

## 验证边界

本地仅编辑、审查、下载报告和校验哈希，没有运行 Android 构建、测试、模拟器或 ADB。设备操作为 API 35 云端模拟器与合成资料；覆盖手机横竖屏、平板尺寸、窄窗口、大字号、阅读/对话/分类/设置/后台服务与已知失败路径。

未将这些结果等同于所有 bug 不存在。真实微信/学校账号扫码、真实课堂课件、各模型服务、厂商后台策略、实机摄像头形状、平板分屏手势、振动硬件与动画帧率仍未做真实设备联调；升级只证明上述 1.0.1 样本保留，不代表所有历史用户数据组合。轮换授权事务的取消边界如上。
