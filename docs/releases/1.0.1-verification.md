# 雨课伴学 1.0.1 验证记录

版本 1.0.1（构建号 24）。用户已明确澄清为“全部弄完再发布”，本次正式签名包的完整验收见下文；开发期间的失败和暂停记录作为历史保留，不替代 1.0.0 的历史记录。

## 修复范围

- 连续阅读吸顶标题移到时间行下方，预留固定的宽幅标题区域；时间与原页页码仍在上层。模拟 40dp 顶部摄像头区域时，上层为 48dp，标题区域为 32dp；较大系统字号时标题区域随字体增加。标题单行省略并保留向上滑入、向下滑出的淡入淡出动画，显隐不推动正文。翻页模式无此吸顶标题。
- 模式、正文字号和阅读宽度改变时使用文字行的字符锚点恢复阅读位置，旧记录无新锚点时兼容旧的偏移。锚点随加密存储和手动笔记备份保留。
- 反向跨页定位到上一段最后一屏，等待所有文字及图片的终态布局；不再以两帧固定延迟替代目标页就绪。
- 长页末尾不足一屏时，前进和后退使用一致屏边界；快速跳转共用取消代次，旧跳转不能在新跳转之后重设位置。
- 仓库与安装包加入用户选择的 MIT 许可。App 声明明确完全开源、原创代码的 MIT 授权、第三方依赖许可、按现状提供及适用法律允许范围内的责任限制，保留资料授权、AI 核对和备份提醒。

## 验证边界

本机只编辑源码、读取报告、计算哈希和复查截图；构建、测试、模拟器和 ADB 均在 GitHub Actions 执行。设备操作使用 API 35 云端模拟器与合成数据。本次已覆盖正式 1.0.0 到 1.0.1 的上述升级样本；不代表已逐一验证所有旧版、图片/分类/草稿组合或用户真实数据。

基线 38 条 Lint 警告分类说明见 [1.0.0 验证记录](1.0.0-verification.md)，开发分支新增 2 条如上。实机摄像头形状、厂商后台策略、真实平板分屏手势、动画帧率、真实微信扫码账号、课堂及模型服务仍需对应设备和账号验证。云端通过限定于上述范围。
