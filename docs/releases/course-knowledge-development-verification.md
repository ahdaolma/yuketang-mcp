# 课程知识开发验收记录

## 当前范围

独立章节总览、知识点来源段落、持续课程范围问答；重复知识合并纳入总览。没有移植 DeepTutor 服务或增加外部知识库，也没有加入练习/间隔复习/掌握度评估。本文件保留开发阶段证据；正式包与发布结果见 [1.0.7 记录](1.0.7-verification.md)。

## 回归与风险复查

- 旧数据：课程范围为空的旧会话保持全局行为；新范围随会话保存。总览来源版本字段可缺失，旧备份仍可读。
- 保存：总览另存，原笔记与个人备注保持；停止、空回答、来源在生成中变化或分类删除时不发布残缺/过期总览。
- 来源：使用实际保存段落的范围与 SHA256；正文新增尾页不使旧段落失效，修改/移动/删除不冒用旧偏移。链接与显示标签只使用本轮实际发给模型的来源。校验链接出处不证明模型结论的事实正确性。
- 对话：默认原笔记，显式选择的总览允许继续追问并注明来源变化；范围删除不扩展全库。退出范围新建对话，不把旧课程的转录暗中带入全局对话，保留旧会话并带上当前未发送的问题和附件。
- 界面：来源面板沿用固定关闭入口和内部滚动；课程范围提示在消息列表外，原有消息索引与最新回答跳转不偏移。列表状态哈希在后台计算，不阻塞长笔记的列表绘制。
- 备份：来源图、来源版本及正文内部链接独立于用户可编辑的关联清单；ID 冲突时整组映射，不把导入总览指向本机同名/同 ID 的另一份笔记。
- 范围：20 份原笔记、总请求源资料最多 60,000 字符；超限明确失败而不生成声称完整的截断总览。检索仍为有界词项相关段落，不声称已经构建全文向量库或完整知识图谱。
- 既有阅读：没有改动连续/点按/横向翻页命令、停页几何、阅读位置或图片批注算法。Markdown 内部链接由当前原生 TextView 转发，缓存 span 不捕获旧页面回调；外链保留原行为。

- 同次 API26 的分类夹具使用 compat 稳定布局 inset 判断系统状态栏，改为既有最低系统阅读用例同样的 `dumpsys window policy` 实际 `WINDOW_STATE_HIDDEN` 断言，并保存系统观测；没有把失败检查删除。来源面板需等待关闭入口实际进入可见区域后截图，不能在弹出动画起点断言已显示。
- 实际 API26 大字号图片显示课程范围提示占用四行，885bf1e 去掉重复说明，范围单行省略并用固定关闭图标退出；需用新图重新验收。
- 885bf1e 的 API26 40648744184 中，实际来源链接未打开：Markwon 默认只在 movement method 为空时设置链接处理，而可选文字已有 ArrowKeyMovementMethod。改由原生短按在实际字形范围内转发当前 TextView 的内部链接回调；长按、拖动仍由选字/阅读处理。原生回归同时检查链接最后一字右半部可点击、相邻空白不误开及只转发一次。其余分类缩放夹具使用 API29 的 WindowInspector，不能在 API26 上据此判产品失败；完整 API35 保留全部用例，最低系统另选 3 个实际可运行的分类流程。
- feb72b0 的 API26 40651220330：16 项中 1 项失败为 Compose 的对话框 PixelCopy 截图仅支持 API28 以上；来源功能断言已通过，后改用真实系统截图和原生显示帧。6a2379d 的 API26 40652117871：19 项中 1 项失败为测试没有滚动有界分类列表就点击屏外末项，补齐真实滚动操作，未去掉列表检查。
- 6712083 的 API26 40681589618 在设备运行前失败：211 项单元中 1 项发现按“第 0045 页”提问虽选对段落，旧节选代码在靠近文末时仍固定丢掉末尾 40 字符。04cdf00 按实际省略提示预算定位起点/终点，只有后面确实遗漏时才显示后文省略提示；同时检查长正文末句、长备注末句、单份和总请求长度预算。失败结果不计入最终通过。
- dfd0c65 的 API26 大字号入口截图仍叠着正在退出的旧分类窗口。Compose 空闲及语义节点消失不足以证明系统窗口动画结束；新增真实屏幕像素连续稳定检查，不修改 App 动画或关闭云端系统动画。旧入口截图不计为静态布局通过证据。
