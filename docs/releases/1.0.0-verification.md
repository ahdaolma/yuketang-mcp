截图收集保留必需画面缺失、重名及意外重复的拦截。仅允许点击翻页与横滑翻页的末页截图相同，因为两者关闭工具后具有相同正文与页码；这两条测试分别检查了所有源段落。三项 Python 回归确保其他重复、第三张旧帧混入或缺失仍会失败。
