影像验收同时补齐分屏面板关闭后的真实窗口移除及连续四张像素一致条件，保留最初过渡帧及稳定帧，实际点击关闭后直接进入对应笔记。它解决的是静态截图捕获时机不足，没有修改产品面板的关闭动画。

候选方案比较和失败基线见[调查计划](../superpowers/plans/2026-10-25-reader-boundary-audit.md)。[Android Lazy layout 指南](https://developer.android.com/develop/ui/compose/lists#tips-on-using-lazy-layouts)要求关注异步加载前后尺寸一致性；[Compose 生命周期](https://developer.android.com/develop/ui/compose/lifecycle)说明移出组合会结束状态及任务；[AtomicFile](https://developer.android.com/reference/android/util/AtomicFile)明确不提供调用者互斥。相关结论结合本项目云端复现，未将官方说明单独当作已修复证据。
