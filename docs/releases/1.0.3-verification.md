## 本轮改动与检查项目

- 点击翻页覆盖正文左右半屏；原图点击仍打开预览，链接、备注与文字选区保留各自操作。慢点、移走再移回和取消不误触翻页。
- 横滑显示真实相邻内容并跟随拖动，未完成拖动回弹；完成后横向过渡再提交原页和阅读位置。长页先看完每屏，反向跨页从上一原页的末屏开始，首尾不循环。
- 恢复、目录、搜索、翻页和几何变化共用可取消的命令代次。旧任务不能覆盖新任务；模式、字号和宽度在拖动中变化时不留下锁住的翻页。
- 修正局部函数引用跨重组保留旧状态的问题，以及系统取消被误当成松手提交的问题。具体失败与修订证据见[调查计划](../superpowers/plans/2026-10-24-reader-audit.md)。
- 第 2→1 页回退检查实际第一页文字和原页计数，并在停留后重复检查；覆盖无焦点、折叠光标、清除选区、关闭图片预览、后台返回。连续两页在单向拖动中不反向，并在停止后收敛。
- 大字号下逐行核对原生正文可达性，覆盖连续、点击和横滑、图片与短长页混排；不以只到达末页替代内容完整检查。
- 原始 UTF-16 源偏移兼容 LF、CRLF 与 CR；人工分段不截断原图引用、代码围栏和表格行，表格续段保留上下文。标记与备注绑定实际源文本，合成重复表头不作为可修改原文，PDF 使用同一源映射。
- 查找不再截断到 100 处；大量结果按紧凑偏移保存、按需生成预览。隐藏链接地址、引用定义和私有图片 ID 不产生假命中，定位使用可见文本序号和有效引用上下文；保留代码字面文本。

## 验证边界

所有 Android 构建和设备操作均由 GitHub Actions 执行；本地仅编辑源码、静态审查、下载证据和校验哈希。云端为 API 35 模拟器和合成资料，不能证明真实学校账号、厂商设备后台策略、摄像头形状、实际动画帧率或所有历史数据组合均已验证。

表格单元格沿用现有 Markwon 替换跨度绘制；本轮检查表格续段和实际可选择正文的源映射，没有将表格单元格内部选字/精确查找作为已新增能力。保留完整原始笔记及编辑、导出路径。
