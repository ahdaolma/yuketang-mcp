# 翻页修改的新增风险复查

遵循用户要求：每次处理后重新问“这样的处理方式会导致新问题的产生吗”，先核对影响范围，再按风险验证。此文件记录开发中的阻断项，不是发布验收结论。

| 处理 | 可能引入的新问题 | 处理与验证状态 |
| --- | --- | --- |
| 图层截图参与翻页 | 原生文字/高亮/图片未进入截图，硬件位图不能直接读像素 | `3a5f048` 的失败确认是测试读取 HARDWARE 位图；复制为可读位图后，`a2574c4` 云端 187 单元、1 设备用例通过。已打开导出的实际位图核对文字、高亮和原图。 |
| 仿真/覆盖替换整页平移 | 页面边缘露白、正反方向错误、翻动中内容缺失 | `72dfdda` 专项 6 用例中 2 失败；`47d03bf` 阅读回归 41 用例中 3 失败，均不用于发布。仿真和覆盖的实际中间帧已有截图；原图颜色的间歇缺失仍在调查。 |
| 捕获与异步目标准备 | 文字已格式化不等于目标已实际绘制；取消后旧截图回写 | 捕获保留命令代次和取消检查，补充实际 draw 次数与像素日志，核对截图时序。尚未完成验证，不认定已排除。 |
| 高度变化时恢复位置 | 查找栏/键盘也会改变高度，恢复旧位置可能覆盖精确查找 | `47d03bf` 日志证实查找命令被高度恢复替代；`b4c31de` 改为仅取消活动纸页几何，保留正文/偏移。旧失败用例和高度取消专项正在云端复验。 |
| 切换动画 | 旧纸页中途按新样式重绘、旧命令稍后提交 | 每轮动作固定其动画选择，切换后通过同一命令取消；加入两种样式的中途切换、持久化及再次翻页验证。完整收尾待最终同一源码回归。 |
| 快照期间手势 | 新按下的手指点到下层文字或图片 | 准备与绘制阶段都拦截新手势，已拥有的拖动保留原手势路径；取消后检查原图预览仍可操作，完整回归待最终源码确认。 |
| 双视口快照内存 | 大窗口/图片增加 GPU 内存；移动时反复截图/排版 | 只在准备时捕获当前/目标视口，进度在 draw 中读取；提交/取消丢弃快照。分配不可用时完成原本计算好的原生目标页，避免崩溃。云端结果不能代表所有厂商设备的性能。 |

最终发布仍需同一源码的全量 Android/Python、固定签名 R8、升级、实际截图核验；不将独立原语、部分专项或旧版的通过结果拼成最终通过。
