# Reader layout corrections implementation plan

**Goal:** 按用户截图修正重复标题、非上课状态悬浮球、阅读菜单的位置和高度、刘海留白，并增加翻页方式。

**Architecture:** 保留隐藏系统状态栏的应用时间栏，将时间与刘海安全高度合并；课程/笔记列表不再使用独立标题栏，操作并入已有内容行，上课卡片保留。悬浮控制仅接受当前服务运行状态，历史记录只提供恢复入口。阅读操作统一使用限高底部面板，翻页偏好持久化，仍复用现有分段及阅读位置。

**Tech Stack:** Kotlin、Compose、现有加密 Saved、GitHub Actions Android 15。

- [ ] StudyDesign/MainActivity：去顶部重复标题，时间栏合并刘海高度，设置入口仍可达，上课卡片恢复。
- [ ] StudyFrame：旧课堂/未启动服务不显示圆钮；本次启动后的暂停仍可用圆钮继续。
- [ ] ReadingActionSheet：笔记选项、阅读跳转及消息跳转固定在底部，最多屏幕约三分之二，分组滚动且关闭按钮固定。
- [ ] NoteReadingControls：上下滚动、左右滑动、固定按钮三种方式，保护多指、选择和垂直手势，持久化偏好。
- [ ] 设备回归按截图复现：无标题、保留卡片、旧课堂无球、限高面板含末尾删除入口、压缩刘海空间、横滑/按钮/目录/位置保持。
- [ ] GitHub 云端全量测试、固定签名与覆盖安装检查；取回 APK、报告及截图，不执行本地构建或测试。
