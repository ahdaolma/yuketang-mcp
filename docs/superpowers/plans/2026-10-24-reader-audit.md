# 笔记翻页再次审计

已有阅读需求保持不变。本批针对 1.0.2 用户再次报告的问题，不把旧测试通过作为本轮结论。全部 Android 构建和运行在 GitHub Actions。

- [x] 重读确认需求，跟踪手势、原生文本、图片和位置恢复路径；发现点击区只有外侧各 25%，与左右半屏说明不符。
- [ ] 在未改生产代码的基线上加入左右半屏、图片点击与翻页冲突、选区交互及逐行可读回归，取得云端失败证据。
- [ ] 独立审查恢复/布局/就绪状态，按确认根因修复；逐项补充可复现用例，不能只修改失败等待条件。
- [ ] 审查短页、长页、图片、格式化文本、双向跨页、模式/字号/尺寸变化、搜索后翻页、恢复及快速交互；核对每行实际可见和上层原页计数。
- [ ] 先规格后质量复核，再执行全量 Android/Python、Lint、实际固定签名包、最新公开版本升级和截图检查。
- [ ] 最终结果、已知限制、包/报告哈希写入独立发布记录；完成后发布正式补丁并重下载核对。

调查专用 workflow `reader-audit.yml` 只运行内部 debug 的阅读用例，不替代全量正式候选验收，也不发布安装包。
