# 小说阅读式翻页动画

用户在原有阅读修复过程中追加要求：动画参考小说阅读器，并明确同时提供仿真和覆盖两种选项。这是本设计的授权依据，继续已有修复与发布任务。

## 阅读行为

阅读设置新增“翻页动画”：仿真翻页、覆盖翻页，默认仿真。选择独立于连续滚动、点击翻页、横向滑屏的阅读方式并持久化；动画用于点击与横滑。连续滚动不插入横翻动画。

长原页仍按屏阅读，上一屏/下一屏不会漏掉段落与图片；反向跨原页先显示上一页末屏。首尾不循环。悬浮工具、上层时间/页码及连续阅读吸顶标题规则保持。

## 视觉

- 仿真：真实当前/目标画面作为纸面，拖动时显示折叠后的纸背、随手指位置变化的折线与柔和明暗。完成卷页后露出目标页，短拖原位恢复。前后翻播放相应折叠/展开方向，不能在中途突然换整张正文。
- 覆盖：目标页位于下层，前景页整页揭开或合上；页边有随进度收敛的阴影，避免两张页面并排推拉的僵硬感。
- 纸面采用现有浅色/深色背景，文字和原图保持原排版。动画只表达用户翻页，其他位置不增加装饰动效或震动。

## 绘制与状态

静止时继续使用现有原生可选择正文、图片及标记交互。动画期间使用固定视口的当前/目标帧；仿真绘制需要的图层快照只在一轮翻页准备时生成，不能每个手指移动都重排文字或截图。帧尺寸必须是完整实际阅读宽度，不能以露出窄条的宽度重新排版。

继续复用单一 ReaderCommandOwner：目标就绪、截图、拖动、松手完成/回弹、切换动画或模式/字号/尺寸都受同一代次取消保护。仅在完成后提交源页、屏内偏移与阅读记忆。未提交帧不参与保存锚点或搜索定位。取消必须清理快照与准备任务，不能跳到第二页。

实现采用 Compose 图层记录/快照及 Canvas/路径/矩阵绘制，不增加第三方翻页引擎或更换依赖版本。先在云端验证原生 TextView、Compose 原图与标题确实进入快照；不能用空纸或占位文字冒充实际纸面。官方 API 参考：[图层绘制与捕获](https://developer.android.com/develop/ui/compose/graphics/draw/modifiers)。

## 验收

云端验证两种效果、两方向、不同拖动进度、松手完成、短拖回弹、系统取消、首尾、长页逐屏、原图与标记，以及动画过程中切模式/字号/窗口和后台返回。保存前后实际正文及源页不变的断言保留。

现有以“双页平移位置”判断动画的断言需要改为对应效果的实际画面验证，不能仅检查页码或语义进度。采集浅/深色、卷页中间帧、覆盖页边、原图画面和取消后截图，验证快照非空、真实相邻内容出现且不窄幅排版。最终固定签名正式包和公开 1.0.2 覆盖升级重新检查。
