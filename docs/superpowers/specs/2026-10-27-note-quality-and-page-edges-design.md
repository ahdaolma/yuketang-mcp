# 笔记整理质量与整行阅读

用户本轮已选择优先改笔记整理质量，并明确要求后续不要提问。保留既有阅读模式、标记、来源图片、编辑与超重点模式，不另起一套笔记窗口。

## 整理质量

参考 [DeepTutor Books 官方文档](https://docs.deeptutor.info/explore/book/) 中按知识组织、基于来源和保留可编辑内容的思路。采用现有逐页生成流水线的渐进改进：传递有来源的知识主题索引和近期已保存正文，提示模型突出本页新增信息、概念间的关系、公式条件和可核对的依据。普通模式按信息需要组织小标题；超重点模式保留同样准确性但删除背景铺垫和例行自测。

仅改提示词会继续丢失早期页内主题；引入完整检索服务器会增加部署与成本。因此在已有有界上下文内加入页内标题索引，保留原页归属，优先近期主题且兼顾早期概念。不新增模型调用，不改写旧笔记，不把用户自定义角色替换成默认角色。索引中的 AI 笔记仍是不可信资料，不能冒充当前课件原文。

## 裁字调查与验收

截图为竖屏，用户描述横屏浏览；同时覆盖横向翻页和短高度/横屏窗口。固定像素步长可能停在原生 TextView 的半行，需要先用真实 Layout 和截图复现。比较单纯加留白、整页重新排版和利用原生行几何的方案；优先保留现有布局与位置映射，基于真实行边界分页，避免延时、预测量和重排引起旧问题。

验收包括每次停页的顶部/底部完整文字、表格单元格跨屏、上标和学习标记、大字号、首尾与反向、查找与选词、源页计数及动画全宽。连续自然滚动不吸附、不回拉。所有 Android 构建与操作仅使用 GitHub Actions，旧 1.0.5 结果不能证明本轮修复。
