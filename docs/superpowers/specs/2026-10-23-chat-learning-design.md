# AI 学习对话与资料流程

用户要求全面检查学习对话，而非仅优化笔记；新增明确问题是课件/笔记讲解后的会话仍为“新对话”。本次沿用原生 Compose 及现有视觉系统，局部重组入口和动作层级，不替换整个导航。

## 行为

- 统一会话自动命名：首次有效提问或单页/笔记讲解以问题/资料来源命名；历史非空但默认名称也补齐；保留所有非默认名称。无需调用额外 AI 服务。空会话仍为新对话，导入文件本身不冒充已发送消息。
- 草稿按会话 ID 保存在 ViewModel，离开学习页和切换会话不会丢失或串用；删除会话清理对应草稿和当前附件。发送成功受理才清空草稿，配置错误保留输入。
- 资料路径显式区分课程、课堂、课件、页面；逐级返回恢复父列表，关闭面板始终独立可达。课堂内部不显示课程活动批次分页。空课件目录亦可返回。
- 课件默认选整份已开放页面，显示数量与逐页保存说明；可切换指定范围并就地验证。整份支持超过 50 页的逐页 checkpoint，不静默截断前 50 页；原有指定范围 50 页跨度限制保留并明确标注。生成前验证模型与图片能力，失败保留面板。
- 主动作“整份讲解并保存笔记”、单页“带入对话 / 本页讲解并保存”与次级 PDF 导出明确区分；点击卡片有类型与箭头提示。学习页可辨认资料入口、当前模型与当前附件，空态按钮直接打开资料。
- 异步读取使用发起时源快照；关闭/离开资料后，旧导入或读取完成不能强制重新打开。生成失败/停止保留已完成笔记，不虚报完成。

## 后续明确追加（同批交付）

- 右上角对话笔记动作明确区分“保存对话原文”和“AI 整理成笔记”；保存原文不调用模型，整理结果在对话中返回真实笔记卡片。
- AI 可访问本机已保存笔记：应用按当前问题、明确选择的笔记以及本会话引用自动检索相关笔记，发送实际原文或明确标注的节选和来源。兼容 Chat Completions/Responses，不仅修改提示词假称已读；不默认发送全部全文。回收站与未保存草稿不进入检索。
- 消息附真实笔记 ID/版本及当时提供的有限快照；卡片可查看/编辑原笔记。下次提问读取最新已保存正文、标记与备注，与上次提供版本比较后传递修改摘要；修改不会在未提问时自动联网。卡片显示已更新/已删除状态，笔记删除后不得继续伪造为当前可读。
- 长按笔记选词菜单改为跟随选区坐标，窗口内避让边缘，保留复制、标记、备注功能，底部只保留收纳悬浮窗。

交互卡片验证增加：检索旧笔记、返回正确 ID、从卡片编辑后下一请求含真实改动、重复标题区分、空库/长文/回收站、原文保存不调模型、AI 整理实际回传卡片，以及长按菜单附近定位。

沿用固定关闭、限高内部滚动的面板；表单和动作使用实际宽度适配，兼容平板、窄屏、短高和 2 倍字号。聊天草稿不在本次新增持久化格式，不承诺进程被杀后的恢复。

增加合成 VM/Compose 回归：自动标题、旧默认名修复、自定义名保留、草稿切换和导航、附件删除、层级返回、整份稀疏页/51 页、错误范围、关闭期间的异步完成、窄屏/横屏/平板截图。所有 Android 构建和测试均在 GitHub Actions；实际微信、课堂和厂商设备仍单独注明边界。最终批次验证完成后再发布正式补丁，不覆盖已发布 1.0.1。
