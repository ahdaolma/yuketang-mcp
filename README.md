# 雨课伴学 / 雨课堂学习桥 MCP

独立安卓 AI 学习客户端采用「学习、课程、笔记」三项导航，通过模型接口或账号授权理解课件并整理笔记。0.9.0 已移除内嵌网页模式和网页跟课；已有笔记、图片、分类与草稿保留。设置按模型与账号、笔记生成、学习偏好、文件与下载分类。

安卓源码、安装与功能边界见 [android/README.md](android/README.md)。GitHub Actions 的 **Android preview** 工作流提供测试与 APK 构建。内置学习助教和笔记助手两套可编辑的角色 Prompt，生成请求自动带入。设置中可填写「我的学习情况」，让讲解与笔记参考自己的基础、难点和目标。

原有 MCP 继续提供微信扫码授权，让支持 MCP 的助手读取自己账号已开放的课程与课件。

**状态：已有本地原型和私有云端版。云端已验证微信二维码图片可读取，真实账号与课件仍待联调；安卓端已通过自动构建与单元测试，尚未完成实机联调。**

## 只有手机：使用私有云端版

手机直接打开：[雨课堂学习桥](https://yuketang-mobile-study.nuttylemur514.chatgpt.site)。

用同一 ChatGPT 账号登录，选择雨课堂版本，再点击“开始微信授权”。可以尝试保存二维码后用微信扫一扫的相册识别；是否允许由微信决定，不支持时需另一台设备协助。授权期间不要关闭页面。登录后核对账号名，再读取课程。

站点已提供私有 MCP 插件；若当前聊天尚未出现“雨课堂学习桥”，可新建聊天后从插件选择器中选中。云端应用层源码与限制见 [cloud/README.md](cloud/README.md)。

## 本地使用：Windows 微信扫码

1. 从仓库绿色 **Code → Download ZIP** 下载，完整解压。
2. 安装 Python 3.11 或 3.12（已安装可跳过），双击 `start_windows.cmd`。
3. 等待安装依赖、自动打开本地设置页，选择微信中的雨课堂版本，点击“显示登录二维码”。
4. 手机微信扫码确认后，核对显示的账号名，再点击“读取课程”。
5. 点击“生成本机配置”，复制到支持 STDIO 的本地 MCP 客户端。

扫码页只在本机 `127.0.0.1:8766` 运行；启动器自动打开带有临时访问凭证的页面。
不要把浏览器地址或登录记录发给别人。生成的 MCP 配置不包含账号 Cookie。
登录完成后可关闭引导程序，本地 MCP 启动时会读取同一登录记录。

如果端口被占用，可在安装依赖后运行 `python server.py setup --port 8767`。
“检查网络”只验证当前选中站点能否响应，不代表账号或课件权限通过。
如果浏览器未自动打开，重新运行启动器；直接手输不带临时凭证的网址无法操作账号。

**此启动器验证的是本地运行。只有手机时，请使用上方云端入口。**

## 目前包含什么

| 工具 | 功能 |
| --- | --- |
| `login_start` | 开始微信扫码登录并返回二维码 |
| `login_status` | 显示登录状态和账号名，不输出凭据 |
| `list_courses` | 读取接口返回的课程批次 |
| `list_course_activities` | 分页读取课程活动，每页 50 条 |
| `list_live_classes` | 查看正在上课的课程 |
| `list_slides` | 读取已知 presentation_id 的课件目录 |
| `read_slide` | 返回单页课件图片与服务器提供的文字 |

MCP 模式由调用方助手完成图片理解，无需在本服务另配模型 API。独立安卓客户端可使用 ChatGPT 账号授权；手动 API 接入时才需填写对应服务的 API Key。

## MCP 的未完成部分

以下限制针对原 Python / 云端 MCP。Android 已另行实现课堂记录 → 课件目录解析与前台翻页监听，边界见 [Android 文档](android/README.md)。

- 微信扫码、账号权限、你学校的接口版本都还需要实测。项目使用学生端网络接口，不是官方开放 API，平台更新可能使其失效。
- 活动里的 `classroom_id`、`lesson_id`、`courseware_id` 不能直接当成 `presentation_id`。只有拿到确切的课件标识才能读页；当前尚未完成各类历史课件和活动到课件标识的统一解析。
- 某些课件要求课堂令牌，本版遇到权限错误会停止；尚未实现课堂授权连接。
- **尚未实现老师当前页自动同步，也无法获知你微信屏幕正在看哪一页。**
- 本地 STDIO MCP 是可测试的目标；HTTP 仅监听 `127.0.0.1:8765`，用于本机调试。此 Python 服务不包含远程部署；手机云端实现位于 `cloud/` 并通过 Sites 身份与私有插件连接。
- 微信扫码成功一般获得同账号会话，但不同区域服务会话独立，需要选对版本。

## Windows 启动

安装 Python 3.11 或 3.12，下载并解压项目。在项目文件夹打开 PowerShell：

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe server.py login --region standard
```

程序会在电脑上打开二维码图片。用手机微信扫描并确认，成功后显示账号名称。
也可以由 MCP 客户端调用 `login_start` 完成登录。

| 微信入口名称 | region 参数 |
| --- | --- |
| 雨课堂 | `standard` |
| 荷塘雨课堂 | `hetang` |
| 长江雨课堂 | `changjiang` |
| 黄河雨课堂 | `huanghe` |

例如荷塘版：`server.py login --region hetang`。网络请求使用系统直连；不自动读取代理环境变量。

## 本地 MCP 客户端

支持 STDIO 的客户端可使用以下配置（将两个路径替换成你的实际绝对路径）：

```json
{
  "mcpServers": {
    "yuketang": {
      "command": "D:\\yuketang-mcp\\.venv\\Scripts\\python.exe",
      "args": ["D:\\yuketang-mcp\\server.py", "serve", "--region", "standard"]
    }
  }
}
```

对于使用 TOML 配置的本地 Codex：

```toml
[mcp_servers.yuketang]
command = 'D:\yuketang-mcp\.venv\Scripts\python.exe'
args = ['D:\yuketang-mcp\server.py', 'serve', '--region', 'standard']
```

启动后先调用 `login_status` 核对账号，再 `list_courses` 和 `list_course_activities`。
若活动返回明确的 `presentation_id`，可调用 `list_slides`，然后按目录的 `page` 调用 `read_slide`。
`page` 从 1 开始，按返回顺序编号；`source_index` 另行保留，避免把服务端索引当页码。

## 登录数据

登录记录默认保存在当前系统用户目录 `.yuketang-mcp/<region>.json`，不在项目目录。
可用 `YKT_STATE_DIR` 改路径。不要将该目录、二维码或 Cookie 上传 GitHub。
文件在类 Unix 系统以 0600 权限写入；Windows 使用当前用户目录权限，未实现凭据库加密。
删除该 JSON 可移除本地保存的登录记录；这不等于注销服务器上的会话。

图片下载单独请求，不附带账号 Cookie；图片域名有限制，遇到未适配的域名会报错。

### 0.8.0 阅读布局

学习页将跳转入口合并到一行，向上阅读时顶部栏和底部导航随手势平滑收窄、标签向下滑出、图标移至紧凑位置，松手后柔和归位，所有按钮保留点击能力；反向滑动恢复，输入和编辑时不触发收窄。横屏短窗口改为左侧导航和单行工具栏，避免正文被顶部和底部控件挤空。长参考笔记默认显示可展开摘要，原文与导出不变；统一 Markdown 标题层级，去掉标题下重复横线，新生成笔记按实际知识组织，封面页简短处理。

微信扫码期间启用有时限的前台连接保持，允许切换微信完成确认；本次二维码不再每 50 秒自动替换。成功、取消和错误都会停止保持，三分钟未完成则明确提示重新获取；四分钟硬上限兜底释放服务。设备回归使用隔离 TLS/WebSocket 和合成账号，覆盖切后台超过原刷新周期、后台确认加密保存及取消后的迟到消息。

横屏输入空间不足时，阅读工具会转为贴边悬浮入口，面板以滑移展开；工具保持可点击，输入草稿、附件与用量入口保留。

笔记支持手动新建、标题/完整正文/来源搜索、重命名与置顶；编辑器提供标题、加粗、列表、待办、引用和代码快捷操作。原有笔记缺少置顶字段时按未置顶读取，不改写原文和课件图片。

### 0.8.1 阅读与笔记整理

- 课程标签直接使用已保存账号与当前课程目录，不在切换标签或回到前台时反复发起验证。未验证账号读取课程时验证一次，仍可手动验证或刷新课程。
- 隐藏系统顶部状态栏；应用只显示本机小时和分钟，回到前台立即校准时间。移除重复的“学习”标题。上滑阅读时工具栏滑入侧边悬浮入口，底部导航保留可点击图标，实际增加正文高度。
- 笔记列表长按或点击更多按钮可编辑、重命名、置顶、移动分类和删除；删除笔记需单独确认。分类可创建、重命名、筛选和删除，删除分类仅将笔记移回未分类，原文、图片和置顶状态保留。
- 新的分类字段向后兼容，旧笔记默认未分类，不改动正文。

笔记进一步支持：编辑页插入、替换、旋转、改说明、移除和撤销图片修改；按课件页选择删除正文和图片引用，确认后才生效。编辑草稿使用独立的加密原子文件自动保存，显示保存成功后可在重开应用时恢复；尚未写完的瞬间强制终止无法保证最后字符。原笔记与草稿分开，放弃草稿不改原文。每份笔记的分段和滚动位置独立加密保存，正文变化时优先按页标题匹配阅读位置。

学习层级以记号笔高亮、蓝色下划线、浅色斜线和易错波浪线呈现，正文不堆叠文字标签。编辑工具可手动添加标记，图例说明 AI 建议优先级与正式考试范围的区别。上课模式在应用内显示可拖动的圆形暂停/继续按钮；拖动不点击，长按不触发操作。切到后台仍按原规则暂停跟课。
