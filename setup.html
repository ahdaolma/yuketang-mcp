雨课堂学习桥 / 本地设置

用微信连接你的课堂。

先登录并确认课程能读取，再把 MCP 配置添加到本地客户端。

1. 微信扫码登录

选择你微信中实际使用的入口。

在电脑显示二维码，用手机微信扫描。无需输入微信密码。

正在检查登录状态…

2. 确认你的课程

登录后核对账号名，再检查课程列表。

    3. 添加到本地 MCP 客户端

    扫码成功后，点击生成配置。配置中的路径对应这台电脑，可供支持 STDIO 的 MCP 客户端使用。

    当前版本尚未部署远程服务，不能直接连接手机里的 ChatGPT 云端聊天。老师当前页自动同步也仍待实现。
    

    登录记录保存在你当前系统用户的本地目录。关闭此窗口不会删除记录；关闭启动终端可停止引导服务。
