1.0.3 修复连续阅读两页抽动、第 2→1 页回弹、长页逐屏漏读与输入丢字，提供可持久切换的仿真/覆盖翻页；短拖取消、原图/选字操作、查找定位、旧标记和 PDF 兼容一并回归。187 项单元、160 项完整云端设备操作通过（0 失败/跳过），最低 Android 8 另有 14 项专项通过；固定签名 R8 正式包、深色/窄屏操作和公开 1.0.2 覆盖升级后的合成笔记及加密偏好保留均通过。构建与设备运行全部在 GitHub Actions，详见 [验证记录](../docs/releases/1.0.3-verification.md)。

连续阅读吸顶标题位于时间行下方，避开中央摄像头；时间和页码仍在上层同行。菜单采用宽幅圆角面板，关闭入口固定、长内容内部滚动。“整本末尾”与“本段底部”定位到对应末行。正式安装包通过 [GitHub Releases](https://github.com/ahdaolma/yuketang-mcp/releases/tag/v1.0.3) 提供，本版实际验证范围以发布说明为准。

笔记阅读提供整本连续滚动、点击左右侧按屏翻页和横向滑屏。每一原页内先按可视高度逐屏前进，最后才进入下一页；页码位于应用时间栏右侧，同一原页的多屏不重复计页。阅读页底部只保留悬浮收纳工具，展开为限高的纵向列表。

阅读设置提供独立的 12–28 sp 正文字号，实时生效并保留；查找增加正文及结果高亮、命中计数、上一处/下一处和定位到命中行。原笔记、附图、草稿和阅读位置保留。

「文件与下载」可导出笔记 ZIP 备份并合并恢复，包含笔记、分类、标签、复习状态、关联、草稿、阅读位置、历史、回收站、原图及图片批注。备份未加密，不含账号登录凭据、接口密钥、聊天或课堂运行状态。恢复不覆盖现有笔记；碰撞的笔记及关联重映射为副本，备份草稿恢复为独立笔记；本机已有同图批注优先保留。外部原始 PPT/PDF 等资料文件不在此备份内。

改进控件按压、滚动取消、多指与键盘操作，避免父子控件同时缩放、长按禁用控件误提示及多指误暂停。文字编辑增加撤销/重做，浮动阅读工具可用返回键收起。

课程页和笔记列表移除重复页面大标题，上课卡片保留。通过「上课管理」打开统一管理面板；阅读笔记时在「笔记选项」、学习页在「会话」菜单中进入。本次启动的课堂暂停后圆形继续按钮仍可用，重启恢复的旧课堂只提供继续入口。主页面切换只淡入当前页，避免旧页面与新页面重叠、快速切换时误触旧控件。

## 0.5.3 固定发布签名

0.5.2 及之前的发布包误用了 CI 临时调试密钥，跨构建会更换签名，导致无法覆盖安装。新的 release 配置只接受外部固定 PKCS12 密钥，不再回退到 debug 签名。仓库只保存公开证书的 SHA-256 指纹，私钥和密码通过 `ANDROID_RELEASE_SIGNING` 仓库 Actions Secret 恢复；密钥备份单独保存，不能放进源码或构建产物。

配置 Secret 后，每次发布必须先校验密钥证书，再使用 Android `apksigner` 校验最终 APK 的固定指纹与 v2 签名，并在一次性模拟器上检查 `adb install -r` 覆盖安装及加密学习设置保留。测试完成后才上传安装包。未配置 Secret 时只跑内部 debug 测试，不发布任何安装包；PR 不发布 release，也不向 fork 提供密钥。

公开证书为 `signing-certificate.pem`，其指纹保存在 `signing-certificate.sha256`。它们只用于核验发布身份，不含私钥；不能从证书恢复丢失的私钥。更换电脑或 CI 环境时应恢复已备份的签名资料，不能创建替代密钥。

旧版临时签名的私钥未被保存，无法从 APK 的公钥证书恢复，因此固定新签名不能直接替代旧签名的安装。旧版用户需先导出笔记再做一次迁移；后续固定签名版本才可正常覆盖更新。不会使用关闭系统签名校验来掩盖问题。

## 0.5.2 网页显示恢复

修复网页直接作为 Compose 原生视图并切换 `INVISIBLE` 时可能留下白色绘制面的路径：网页固定放在保留尺寸的原生容器内，切换标签只改变容器透明度，隐藏时拦截触摸并移出无障碍遍历。重新显示、尺寸变化及页面提交后，使用 WebView 的 visual state callback 等待当前内容可绘制，再请求刷新，不重新加载对话或覆盖草稿。加载进度还会等待绘制准备完成。

新增设备回归：使用同一发布页面容器，在隐藏标签加载合成网页，切换课程、笔记、设置并返回，改变宽度和主题；验证真实窗口像素中的两种固定色块，而不只检查 DOM/无障碍文字，同时确认草稿保留。此测试验证原生显示路径；无法代替用户手机上的网络、官网验证或账号登录检查。

- 课程中选择单页后，点击「带入课件」，将文字和图片放进网页输入框，用户核对并发送。
- 「保存回答」读取最后一条已完成的网页回答，保留标题、列表、代码、表格与可提取的公式为 Markdown 笔记。生成中、不匹配或不稳定的回答不会写成完成笔记。
- 网页可通过系统文件选择器上传图片/PDF/文本；不开放本地文件 URL、任意网页脚本桥或证书忽略。App 不读取/导出网页 Cookie、令牌或登录密码。
- 嵌入式网页登录可能受 Google/Apple/官网验证限制。提供系统浏览器入口；系统浏览器会话与嵌入页面不互通，不能将外部浏览器打开成功称为 App 自动跟课成功。

### 网页跟课适配（实验功能）

需在设置明确启用，首次显示其操作内容。先在学习页登录 ChatGPT、进入可用对话并选择网页模式，再在课程页开启上课模式；也可按范围逐页整理。

适配只操作可见的网页输入框、附件和发送按钮，并读取对应页面回复；**不调用 ChatGPT 私有接口，也不把 OAuth 令牌用于网页后台接口**。每页按当前笔记 Prompt 发送一次，关联独立标记；完成后追加到同一份课堂笔记。上课流程继续按课件页码去重、顺序处理和逐页保存。

发送前将待处理标记加密落盘。取消、超时、对话切换、页面结构不识别或网页额度提示导致无法完成时暂停，不自动再次点击发送。重开后可进入待完成对话并「恢复回答」，确认标记和生成完成后再保存；只有用户明确确认后才能清除待处理标记。网页中人工草稿或已有附件不会被覆盖。

0.4.1 复查修复：恢复地址只绑定包含本页标记的对话，绑定后不会随用户切换对话而改变；连续整理的待完成回答关联原笔记，恢复后追加并更新完成数量。笔记及完成队列成功写入文件后才清除待处理标记，写入失败仍保留恢复入口；写入期间新到达的课堂事件会合并保留。正在整理或待恢复的笔记禁止编辑和删除，进入编辑时读取最新正文，避免旧草稿覆盖新增讲解。

此适配依赖网页结构，不是官方稳定的自动化接口。CI 只用本地网页样本验证真实 Android WebView 的附件、输入、发送、完成检测和 Markdown 提取，**没有登录真实账号或验证当前线上页面结构**。真实登录、模型模式、用量、上传和老师翻页必须在用户手机测试；失败时展示原因，不自动改走接口。

设置中的「模型接口」保留原有原生 AI 模式，需用户显式选择，账号与 API 配置均不删除。该路径的 ChatGPT 套餐授权受第三方应用用量限制，与网页聊天不同。

## 上课模式

雨课堂页 → 查找正在上的课 → 进入课程。**进入会向雨课堂登记入课**，获取当前账号的课堂令牌；只读取课件与翻页事件，不自动答题、发送弹幕或处理位置签到。

- 监听 `hello / fetchtimeline / showpresentation / slidenav / slide`，从时间线补齐已展示的页面，不推测老师尚未展示的页面。
- 每个「课件编号 + 页码」只生成一次，老师回翻不会重复调用模型。翻页快时排队逐页生成，展示待处理数量。
- 每一页完成后，将讲解追加到同一份笔记并加密保存。已完成键和待处理队列也会保留；恢复后避免重复。单页未完成时不写成已完成笔记。
- 支持暂停、继续、结束；连接断开最多自动重连 4 次，重新读取时间线。失败会显示原因并暂停，保留笔记。
- **本版仅前台跟随，切到后台自动暂停；返回后手动继续。** 运行时保持屏幕常亮。跟课没有后台服务或录音，也不会把 AI 补充冒充老师口述。
- 停止本节课会保留完成的笔记并停止剩余队列；下课事件会先整理队列内剩余页面。

## 课件、笔记与模型

历史活动的 type 14 `courseware_id` 先作为课堂编号读取 `classroom-report/student/lesson-info`，从 `presentationIds` 获取真实课件；再用课堂编号和课件编号读取 `classroom-report/student/ppt`。仅展示开放的 `slideList.visible` 页面，保留服务端页码。明确的 presentation_id 仍支持直接读取，不把课程编号当作课件编号。

可添加单页到对话，或选择最多 50 页连续整理到一份笔记。讲解型笔记按资料内容提供概念、机制、公式条件、对照表、易错点、AI 举例和带答案的自测；保留来源，区分 AI 补充与原页内容。笔记支持编辑和 Markdown 导出。运行中的课堂笔记暂不允许手工修改或删除。

内置学习助教与笔记角色 Prompt，可编辑；应用环境和资料处理规则每次都会附加，包括缺少课件时引导应用内选择、不默认索要截图、不声称具有未实现的操作工具。

设置中统一使用「配置模型」。首次安装不预置特定服务商或模型；原有已填写的模型配置保留。

### 使用 ChatGPT 账号

设置 → 模型接口 → 配置模型与账号 → **Continue with ChatGPT** → 在本机系统浏览器登录并授权 → 点击「返回雨课伴学」→ 选择账号返回的模型 → 保存并使用。

此方式不要求 API Key。符合资格的请求使用账号授权的 ChatGPT 套餐或额度，可用性由账号、工作区、地区和官方授权结果决定。不绕过权限，也不把登录成功视作模型请求已验证。

- 使用官方开源/本机客户端的动态注册流程，稳定保存 host ID；不借用其他客户端的 ID 或抓取 ChatGPT Cookie。
- 回调仅监听本机 `127.0.0.1` 的随机端口，绑定一次性 state、nonce、S256 PKCE 和精确回调地址；校验签名、issuer、audience、有效期和账号身份后才保存。
- 登录时短暂运行带通知的前台服务，保持切到系统浏览器后的本机回调可用；完成、取消或超时后关闭。这项服务不让上课模式在后台运行。它仅用于可选接口模式；网页直接使用官网自身登录。
- 多个账号/工作区注册分别保存，支持重新授权、切换和退出。拒绝使用套餐时保留已验证身份，显示「尚未授权套餐」，不发起模型请求。
- 授权与刷新记录使用现有 Android Keystore 加密存储。接近到期时串行刷新，一次保存更新后的 access / refresh token；临时网络错误不会删除登录。
- 模型列表使用账号返回的 `models`，过滤 `visibility=list`、保留顺序、展示 `display_name`，以 `slug` 请求 Responses。
- 聊天、笔记和上课模式共用此授权；请求固定发送到 `https://api.openai.com/v1/responses`，使用 `store=false`、`stream=true`，收到 `response.completed` 才视为完成。
- 使用套餐时展示用量入口；不支持、受限或失效会明确提示，不自动改为 API 付费。

也可以手动添加其他模型接口（Chat Completions / Responses），用户自行填写对应服务的配置。账号授权与 API 配置分别保存，不会将 ChatGPT 令牌发往自定义服务地址。

这是本应用的模型接入与学习流程，并不嵌入官方 Chat / Work 的全部工具。官方协议来源：
- https://developers.openai.com/siwc/token-sharing-open-source/sign-in
- https://developers.openai.com/siwc/token-sharing-open-source/profiles-and-sessions
- https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference
- https://developers.openai.com/siwc/token-sharing-open-source/errors-and-recovery

## 安装与构建

Android 8.0 及以上。GitHub Actions → Android verification → Artifacts → study-bridge-android-release，解压安装 `app-release.apk`。正式发布后也可从仓库 Releases 获取 APK。

0.5.3 起采用固定发布签名；新版本需保持相同密钥并递增版本号。0.5.2 及之前属于旧临时签名，首次迁移前需导出重要笔记。卸载会删除本机密钥与记录，不能跳过备份。

JDK 17、Gradle 8.11.1、SDK 35，在 `android/` 执行：

```sh
gradle testDebugUnitTest assembleDebug
```

本地 release 构建需先通过环境变量提供固定密钥路径、别名及密码（`RAIN_SIGNING_KEYSTORE`、`RAIN_SIGNING_KEY_ALIAS`、`RAIN_SIGNING_STORE_PASSWORD`、`RAIN_SIGNING_KEY_PASSWORD`）。`python3 scripts/verify_signing.py` 使用 SDK 35.0.0 的 apksigner 检查发布身份。切勿重新生成密钥来处理缺失配置。

Release 启用 R8 与资源收缩。聊天流式文字按时间/大小合并刷新；生成中显示纯文字，结束后解析 Markdown；图片解码与 Markdown 解析移到后台，减少主线程负担。

## 数据与验证边界

模型凭据、ChatGPT 授权记录、雨课堂登录记录、聊天和笔记使用 Android Keystore 的 AES-GCM 加密写入本机应用私有目录。不申请无障碍、读屏、麦克风或联系人权限。选择的课件图片/文字会直接发送给配置的模型服务商，不提供 OCR 自动降级链路。

收到登录 Cookie 后先保存，再单独验证账号资料；资料请求失败保留记录，可重试。诊断进度不展示登录令牌或密钥。

CI 执行单元测试、Release 构建、默认网页/三个学习标签/设置/授权入口及取消检查，以及独立的 Android WebView 样本测试、原生按钮真实触摸与禁用原因测试。OAuth 测试使用本机回调、临时测试签名和模拟端点，不使用真实用户登录。真实账号、学校地区接口、老师实际翻页、模型权限、网络延迟与设备帧率仍须手机联调，不能仅凭编译通过宣称全部可用。雨课堂接口未获官方稳定性保证；不支持的活动或未开放课件会如实提示。

本客户端独立实现，未复制或打包 RikkaHub 源码。


## 0.7.0 图文阅读与定位

- 原生对话与 ChatGPT 网页都有固定的顶部、底部和消息跳转入口；消息列表支持序号 / 关键词定位。网页跳转只滚动当前已加载的消息，不改写草稿或发送提问；页面内容改变时会拒绝过期目标。
- 课件列表按需显示首页缩略图（课堂记录显示首份课件首页），课件内各页可预览、放大、双指缩放和页码定位。雨课堂图片及 PDF 为原页；PPTX/DOCX 使用文字和嵌入图片提取预览，复杂版式仍建议先转 PDF。
- 新生成的单页、连续和课堂笔记会保存本次实际读取的原页图片。每个原页与对应讲解放在同一阅读段，长页继续按上限分段，目录入口固定可见；导入的原始笔记也能逐页查看。
- 图片保存在应用私有目录，按内容去重；网页中断恢复保留图片引用。旧的纯文字笔记若没有保留原图或导入原件，无法凭页码补回原图。
- Markdown 导出将本机图片转换为内嵌 data URI，逐图片写入临时文件，避免将整份图文课件一次性复制到内存。部分 Markdown 阅读器不支持 data URI，可用支持内嵌图片的阅读器打开。
- 缩略图在后台按需加载、最多两个同时处理，磁盘缓存上限 40 MB；原页图片独立保存，清理缩略图不会删除笔记图片。删除笔记后，下次启动清理不再被笔记或待恢复任务引用的图片。
