# 雨课伴学 Android 初版

独立的安卓 AI 学习客户端，以「配置自己的模型 → 连接雨课堂 → 选择课件 → 聊天 / 自动整理笔记」为主流程。现有 Python / 云端 MCP 保留，安卓端不依赖 ChatGPT 登录。

## 安装与构建

Android 8.0 及以上。GitHub 仓库的 **Actions → Android preview → 成功的运行 → Artifacts → study-bridge-android-preview** 可下载 APK 压缩包，解压后安装 `app-debug.apk`。预览包使用构建机临时调试签名，不是稳定发行版本；不同构建间升级可能需要卸载，务必先导出重要笔记。

本地需要 JDK 17、Gradle 8.11.1、Android SDK 35：在 `android/` 执行 `gradle testDebugUnitTest assembleDebug`。本仓库未附带 Gradle 二进制 wrapper。

## 功能

- 多模型配置：名称、HTTPS Base URL、API Key、模型 ID、图片支持开关。首版支持 OpenAI Chat Completions 兼容协议，预置 DeepSeek 地址与 `deepseek-flash`；模型 ID 可自行修改。
- 流式聊天、会话切换、停止生成、Markdown 展示。
- 内置「学习助教」和「笔记整理助手」两套中文角色 Prompt，每次请求作为 system 消息发送。支持查看、编辑、恢复默认，切换服务商时继续使用。
- 雨课堂 / 荷塘 / 长江 / 黄河入口；微信二维码授权、课程列表、活动分页、明确 presentation_id 的课件目录、选择单页附到对话。
- 自动笔记：在笔记页开启「添加课件后自动整理」，每次添加一页后调用当前模型，按知识点、公式、例题、易错点与复习问题生成笔记。也可手动从当前课件或对话生成。
- 笔记保留来源课件和页码、所用模型；可编辑、删除并导出 Markdown。

## 数据

模型请求从手机直达用户填写的服务商。选中的课件页与对话会随请求发给该服务商；不会把全部课程自动上传。课件图片要求所选模型支持图像输入，纯文字模型不能直接看图。本版没有 OCR 降级链路。

API Key、雨课堂会话、聊天和笔记通过 Android Keystore 的 AES-GCM 加密写入应用私有目录，不加入系统备份。不申请无障碍、读屏、联系人或存储访问权限。Android 10 及以上通过系统图片库保存二维码；旧版通过系统文件选择器导出。

## 验证边界

编译、单元测试与真实账号流程分开验证。微信是否允许相册识别当前二维码由微信决定；不支持时仍需另一设备展示二维码。不能仅凭二维码生成成功就声称手机微信授权成功。

雨课堂使用非官方学生端网络接口，学校版本及课件开放权限仍需真实设备联调。活动缺少明确 presentation_id 时不会猜测；课件需要课堂令牌时本版会停止。尚未实现教师当前页实时同步、后台课堂录音、整份课件批量笔记、跨设备同步或通用 MCP 客户端。

本客户端为独立实现，未复制或打包 RikkaHub 源码。
